## Decisions made

- **XGBoost is the canonical model** — `xgb_loan_default.pkl` trained on the full 1.38M-row LendingClub dataset is the artifact the inference endpoint loads. The RF artifact is retained but not served.
- **Inference API accepts raw inputs** — grade is received as a letter string (A–G) and mapped to ordinal (1–7) inside `predict.py` rather than expecting the caller to pre-encode. Same for homeownership and other categorical fields. This keeps the API contract human-readable.
- **Validation is non-blocking in pipeline** — `run_data_pipeline(validate=False)` skips checks (default fast path); `validate=True` prints GO/NO-GO and raises on critical failures. Kept optional so pipeline can run for training without hard-failing on benign distribution shifts.
- **Data files stay out of repo** — `.gitignore` excludes all `data/raw/` and `data/processed/` content. Model artifacts (`*.pkl`) are committed to the branch for inference to work without retraining.

## Known open issues

- **CLAUDE.md is stale** — Known Gaps items 1–3 (validation layer, pipeline orchestrator, inference endpoint) are completed but still listed as gaps. Architecture table also shows stale statuses for those modules.
- **`requirements.txt` has no version pins** — any `pip install` will pull latest versions. Pin at minimum: `xgboost`, `scikit-learn`, `fastapi`, `uvicorn`, `pandas`, `pyarrow`, `numpy`. Breakage risk is highest for `xgboost` (API changes between major versions) and `scikit-learn`.
- **Inference API has no input validation beyond Pydantic types** — `grade` is accepted as any string; passing `"Z"` will hit a KeyError in the ordinal map inside `predict.py`. Add a `validator` or `Field(pattern=...)` constraint on the `grade` field.
- **API loads model on startup with no fallback** — if `models/xgb_loan_default.pkl` is absent (e.g., fresh clone without the artifact), `api.py` raises at import time with an unhelpful `FileNotFoundError`. Add a clear startup error message pointing to the re-train instructions.
