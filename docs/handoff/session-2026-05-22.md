## Clarified Project Goal

The goal is to develop the engineering discipline of an ML engineer — the ability to wrap a clean, reproducible, testable *system* around a data science problem. Not to achieve the highest AUC-ROC.

**Primary focus:** feature engineering and pipeline architecture
**Secondary focus:** data validation, experiment tracking, API deployment, MLOps

The gap between the written goal doc and the actual repo revealed three things the original goal was missing:
1. **Testing** — not mentioned at all, yet foundational to the "production quality" claim
2. **Active doc maintenance** — `feature_log.md` and `experiment_log.md` existed as empty files; a log no one writes is not a log
3. **Pinned dependencies** — reproducibility requires version-locked environments, not just package names
